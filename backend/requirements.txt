# =============================================================================
# SSTG Backend — Python Dependencies
# Fully compatible with Python 3.9 → 3.14
# Install:  pip install -r requirements.txt
# =============================================================================
#
# WHY THESE SPECIFIC PACKAGE CHOICES (Python 3.14 compatibility notes)
# ─────────────────────────────────────────────────────────────────────
#
# REMOVED  passlib      → Last release 2020. Imports `cgi` module (removed in
#                         Python 3.13). Raises ImportError on 3.13+. No 3.14 wheel.
#                         Replaced with: bcrypt>=4.2.0 (used directly).
#
# REMOVED  python-jose  → Last release 2021. CVE-2024-33663, CVE-2024-33664.
#                         Depends on `ecdsa` which also has no 3.14 wheel.
#                         Replaced with: PyJWT>=2.9.0 (actively maintained).
#
# CHANGED  psycopg2     → psycopg[binary]  (psycopg v3, the official successor).
#                         psycopg2 binary wheels lag by months on new CPython releases.
#                         psycopg3 publishes wheels the same day as CPython releases.
#                         API differences: connection strings are identical, but
#                         async support is now native (no gevent hacks needed).
#
# CHANGED  datetime.utcnow() → datetime.now(timezone.utc) throughout the codebase.
#                         utcnow() is deprecated since Python 3.12 and raises
#                         DeprecationWarning. Removed from the stdlib in 3.14.
#
# UPGRADED pydantic      → >=2.10 for guaranteed pydantic-core 3.14 wheels.
#
# uvloop NOTE: uvicorn[standard] pulls in uvloop (C extension). If uvloop has no
#   3.14 wheel yet, install without the extra: `pip install uvicorn` then add
#   `httptools` manually. The app works fine without uvloop (just slightly slower).
#
# =============================================================================

# =============================================================================
# TROUBLESHOOTING PYTHON 3.14 INSTALL ISSUES
#
# If a package fails because no wheel is available yet:
#
#   1. Try the latest version first (wheels often land within days of CPython release):
#      pip install --upgrade <package>
#
#   2. Install from source (needs a C compiler: gcc/clang + python3.14-dev):
#      pip install --no-binary <package> <package>
#
#   3. For uvloop specifically (pulled in by uvicorn[standard]):
#      pip install uvicorn            # without [standard]
#      pip install httptools          # keeps HTTP performance
#      # uvloop is optional — the server runs fine without it
#
#   4. For psycopg[binary] (PostgreSQL driver):
#      pip install "psycopg[binary]"  # try binary first
#      pip install psycopg libpq-dev  # compile from source if binary missing
#      # OR: use SQLite for local dev — no PostgreSQL driver needed at all
#
#   5. Check wheel availability before installing:
#      pip index versions <package>
# =============================================================================
